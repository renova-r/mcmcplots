# mcmcplots

Provides functions for conveniently plotting and viewing MCMC output.

Compatibility updates by Renova.

Version 0.4.3.9001: Removed the DESCRIPTION Date field and qualified the denstrip link in man/caterplot.Rd to its source package.

## Install

```r
install.packages("remotes")
remotes::install_github("renova-r/mcmcplots@renova-0.4.3.9001")
```
